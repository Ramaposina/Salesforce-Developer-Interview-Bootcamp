# Salesforce Interview Readiness Bootcamp – Day 4
## Lightning Web Components (LWC)

### 1. What is LWC?

Lightning Web Components (LWC) is Salesforce's modern user interface framework built using standard web technologies such as HTML, JavaScript, and CSS. It is used to create fast, reusable, and responsive components that interact with Salesforce data through Apex.

---

### 2. What did you build?

I built my first Lightning Web Component named **placementHome** for the Placement Management System.

The component displays a welcome message:

> **Welcome to Vishnu Placement Portal**

I also learned how to deploy the component to a Lightning App Page and prepare it for future enhancements such as data binding, event handling, and Apex integration.

---

### 3. Which file contains HTML?

The HTML code is stored in:

```
placementHome.html
```

This file is responsible for defining the user interface, including text, buttons, images, and page layout.

---

### 4. Which file contains JavaScript?

The JavaScript code is stored in:

```
placementHome.js
```

This file contains the component's logic, including variables, functions, event handling, and communication with Apex in future implementations.

---

### 5. What did you learn today?

Today I learned:

- What Lightning Web Components (LWC) are and why Salesforce introduced them.
- The structure of an LWC project.
- The purpose of the HTML, JavaScript, and Meta XML files.
- How to create an LWC using Salesforce CLI.
- How to deploy an LWC to a Salesforce org.
- How to expose a component using the Meta XML file.
- The basics of data binding and event handling.
- How LWC fits into the Salesforce architecture and interacts with Apex and the Salesforce database.
